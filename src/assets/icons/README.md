# Local icons

Brand SVGs are curated from Simple Icons (CC0) and Font Awesome Free (CC BY 4.0). Exact upstream URLs and attribution are retained in `sources.json`; full licenses are adjacent. Generic website, email, and external-link icons are from [Lucide](https://lucide.dev), under its ISC license (`lucide.txt`). Brand marks remain their owners’ trademarks.

Normal builds use these files and never fetch icons. `scripts/vendor-icons.mjs` is an explicit maintainer-only refresh tool, pinned to upstream revisions.
